# Fontes e proveniência

O preview consulta a API de Dados Abertos da Câmara dos Deputados:

`https://dadosabertos.camara.leg.br/api/v2`

As seções de identificação, histórico, proposições, órgãos e despesas abrem o endpoint correspondente em nova aba. A data de coleta é mostrada no perfil e no cabeçalho da seleção.

Uma proposição listada por vínculo de autoria não é tratada como prova de aprovação, implementação ou responsabilidade exclusiva. Histórico cadastral da Câmara não é apresentado como histórico eleitoral completo. Gastos da cota parlamentar são exibidos como valores documentais e não como indício automático de irregularidade.

Casos jurídicos não entram automaticamente a partir de notícias ou respostas de IA. A interface mostra a metodologia de classificação e mantém a seção sem registros quando não existe revisão documental publicada.
